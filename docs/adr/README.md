# Architecture Decision Records

ADRها تصمیم‌های معماری پذیرفته‌شده را ثبت می‌کنند. وضعیت هر ADR یکی از `Proposed`، `Accepted`، `Superseded` یا `Deprecated` است.

| ADR | عنوان | وضعیت |
|---|---|---|
| [0001](0001-production-system-of-record.md) | منبع حقیقت Production | Accepted |
| [0002](0002-branch-and-deployment-policy.md) | سیاست Branch و Deployment | Accepted |
| [0003](0003-auxiliary-ai-stack.md) | مرز AI Stack کمکی | Accepted |

تغییر یک تصمیم پذیرفته‌شده باید با ADR جدیدی انجام شود که سند قبلی را Supersede کند.
