# بررسی بصری کادر جست‌وجوی جمع‌وجور Home

- صفحهٔ محلی Home پس از بارگذاری، لوگوی مغز و پرسش مرکزی را نمایش داد.
- textarea چندخطی بلند به input جست‌وجوی تک‌خطی تبدیل شده است.
- عبارت «جست‌وجو در مقالات منتشرشده» از بدنهٔ کادر حذف شده است.
- کادر با ارتفاع استاندارد (48px در نمای پایه و 56px از breakpoint کوچک) و دکمهٔ آیکونی جست‌وجو درون field رندر می‌شود.
- label قابل‌دسترسی و placeholder فارسی/انگلیسی، autocomplete و navigation پیشنهادها حفظ شده‌اند.

ارسال عبارت «پژوهش» با Enter، مسیر کاربر را به `/read?q=پژوهش` هدایت کرد؛ بنابراین تبدیل textarea به input تک‌خطی، مسیر فعلی جست‌وجوی مقاله را تغییر نداده است. نتیجهٔ آن عبارت در دادهٔ محلی صفر مقاله بود، اما route و حالت empty-state به‌درستی رندر شدند.
