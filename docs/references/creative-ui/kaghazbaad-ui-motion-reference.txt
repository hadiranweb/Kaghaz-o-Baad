### لایه ۱ — Hero Section
**الگو: `sylva` + `kage`**

**مشکل فعلی:**
صفحه با یک عنوان ساده و یک جمله شروع می‌شود — بدون هیچ تجربه‌ای.

**تغییر پیشنهادی:**

در Sylva، هر لایه‌ای که `--pd` دارد، با pointer parallax جابه‌جا می‌شود — loop مقدار eased را مستقیم روی transform می‌نویسد.

همین تکنیک را برای Hero کاغذ و باد:

```tsx
// HeroSection.tsx
// استعاره: کاغذی که در باد می‌لرزد

const HeroSection = () => {
  const [mouse, setMouse] = useState({ x: 0, y: 0 });

  useEffect(() => {
    const handle = (e: MouseEvent) => {
      setMouse({
        x: (e.clientX / window.innerWidth - 0.5) * 20,
        y: (e.clientY / window.innerHeight - 0.5) * 10,
      });
    };
    window.addEventListener("mousemove", handle);
    return () => window.removeEventListener("mousemove", handle);

    <section className="hero relative min-h-screen flex flex-col 
                        items-center justify-center overflow-hidden

          transform: `translate(${mouse.x * 0.3}px, ${mouse.y * 0.3}px)`,
          transition: "transform 0.8s cubic-bezier(0.23, 1, 0.32, 1)",

          transform: `translate(${mouse.x * 0.6}px, ${mouse.y * 0.6}px)`,

        }}
      />

      {/* لایه‌ی اصلی — متن */}

        className="relative z-10 text-center px-6 max-w-3xl"
        style={{
          transform: `translate(${mouse.x * 0.1}px, ${mouse.y * 0.1}px)`,
          transition: "transform 0.3s cubic-bezier(0.23, 1, 0.32, 1)",
```

### لایه ۲ — Scroll = حرکت بین فصل‌ها
**الگو: `kage`**

`kage` یک سایت استاتیک کوچک است که `index.html` شامل document structure، CSS، procedural scene و scroll choreography است.

در kage دوربین با اسکرول حرکت می‌کند — یعنی **اسکرول = باد**.  
در کاغذ و باد همین منطق را برای اسلایدها:

```tsx
// SlideViewer.tsx
// هر اسلاید = یک کاغذ که باد می‌برد

const SlideViewer = ({ slides }) => {
  const containerRef = useRef(null);
  const { scrollYProgress } = useScroll({ container: containerRef });

  return (
    <div ref={containerRef} className="relative h-screen overflow-y-scroll">
      {slides.map((slide, i) => {
        // هر اسلاید با اسکرول وارد می‌شود — مثل کاغذی که باد می‌آورد
        const slideProgress = useTransform(
          scrollYProgress,
          [i / slides.length, (i + 1) / slides.length],
          [0, 1]
        );

        const y = useTransform(slideProgress, [0, 1], ["40px", "0px"]);
        const opacity = useTransform(slideProgress, [0, 0.3], [0, 1]);

        return (
          <motion.div
            key={slide.id}
            style={{ y, opacity }}
            className="slide-card sticky top-0 h-screen flex items-center
                       justify-center bg-white/80 backdrop-blur-sm
                       border border-stone-100 rounded-2xl mx-4 my-2"
          >
            <SlideContent slide={slide} index={i} />
          </motion.div>
        );
      })}
    </div>
  );
};
```

### لایه ۳ — Page Turn برای اسلاید
**الگو: `sketchbook` + `complete-shelf`**

Sketchbook یک اسکیس‌بوک ورق‌زن است — صفحه را drag می‌کنی و ورق مثل کاغذ واقعی خم می‌شود، بعد می‌توانی ذره‌بین را روی آن بکشی.

همه‌چیز در `index.html` زندگی می‌کند: layout، styles، page-turn geometry، loupe، و interaction state.

برای کاغذ و باد — نه یک carousel معمولی، بلکه یک page turn واقعی:

```tsx
// KitePage.tsx
// کاغذی که ورق می‌خورد

const KitePage = ({ current, next, onFlip }) => {
  const [dragX, setDragX] = useState(0);
  const isDragging = useRef(false);

  // محاسبه‌ی زاویه‌ی خم‌شدن — مثل sketchbook
  const foldAngle = Math.min(Math.abs(dragX) / 200, 1) * 180;
  const isFlipping = foldAngle > 90;

  return (
    <div className="page-container relative w-full aspect-[3/4] 
                    perspective-[1200px]">
      
      {/* صفحه‌ی فعلی */}
      <motion.div
        className="page absolute inset-0 bg-[#faf9f6] rounded-xl
                   shadow-lg origin-left cursor-grab active:cursor-grabbing
                   border border-stone-100"
        style={{
          rotateY: dragX < 0 ? Math.min(-dragX / 2, 90) : 0,
          transformStyle: "preserve-3d",
        }}
        drag="x"
        dragConstraints={{ left: -300, right: 0 }}
        onDrag={(_, info) => setDragX(info.offset.x)}
        onDragEnd={() => {
          if (Math.abs(dragX) > 150) onFlip();
          setDragX(0);
        }}
      >
        {/* محتوای اسلاید */}
        <div className="p-8" dir="rtl">
          <span className="text-xs text-stone-400 tracking-widest uppercase">
            اسلاید {current.order}
          </span>
          <h2 className="text-2xl font-medium text-stone-800 mt-3 mb-4">
            {current.title}
          </h2>
          <p className="text-stone-600 leading-relaxed">
            {current.body}
          </p>
        </div>

        {/* لبه‌ی کاغذ — وقتی می‌کشی */}
        {dragX < -20 && (
          <div
            className="absolute right-0 top-0 bottom-0 w-8
                       bg-gradient-to-l from-stone-200/50 to-transparent
                       rounded-r-xl"
          />
        )}
      </motion.div>

      {/* اسلاید بعدی — زیر فعلی */}
      <div className="page absolute inset-0 bg-white rounded-xl 
                      shadow-sm border border-stone-100 -z-10">
        <div className="p-8 opacity-50" dir="rtl">
          <h2 className="text-2xl font-medium text-stone-700">
            {next?.title}
          </h2>
        </div>
      </div>
    </div>
  );
};
```

### لایه ۴ — Navigation Dock
**الگو: `sylva`**

در Sylva، dock با `data-dock` و `data-burst` مشخص می‌شود — هر آیتم با `--d` (delay) تنظیم می‌شود و با proximity magnification کار می‌کند.

```tsx
// KiteDock.tsx
// نخ بادبادک — همیشه در دسترس

const KiteDock = ({ sections, activeId, onNavigate }) => {
  const [hoveredIdx, setHoveredIdx] = useState<number | null>(null);

  const getScale = (idx: number) => {
    if (hoveredIdx === null) return 1;
    const dist = Math.abs(idx - hoveredIdx);
    return dist === 0 ? 1.5 : dist === 1 ? 1.25 : 1;
  };

  return (
    <nav
      className="fixed right-6 top-1/2 -translate-y-1/2 z-50
                 flex flex-col gap-2 items-center"
    >
      {/* نخ بادبادک */}
      <div className="absolute top-0 bottom-0 w-px bg-stone-200/60 
                      left-1/2 -z-10" />

      {sections.map((section, idx) => (
        <motion.button
          key={section.id}
          onClick={() => onNavigate(section.id)}
          onHoverStart={() => setHoveredIdx(idx)}
          onHoverEnd={() => setHoveredIdx(null)}
          animate={{ scale: getScale(idx) }}
          transition={{ type: "spring", stiffness: 400, damping: 25 }}
          className={`
            w-2 h-2 rounded-full transition-colors duration-300
            ${activeId === section.id
              ? "bg-stone-700 w-3 h-3"
              : "bg-stone-300 hover:bg-stone-500"
            }
          `}
          title={section.title_fa}
        />
      ))}
    </nav>
  );
};
```

### لایه ۵ — Falling Leaves / Wind Particles
**الگو: `kage` → `Skills`**

ریپوی Skills شامل تکنیک‌های falling leaves و pointer trail است که مستقیماً از Kage استخراج شده‌اند.

این‌ها را برای کاغذ و باد به «برگ‌های کاغذ» تبدیل می‌کنیم:

```tsx
// WindParticles.tsx
// کاغذهای کوچکی که در باد رها می‌شوند

const WindParticles = () => {
  const particles = useRef<Particle[]>([]);

  useEffect(() => {
    // هر ذره = یک کاغذ کوچک در باد
    particles.current = Array.from({ length: 12 }, (_, i) => ({
      id: i,
      x: Math.random() * 100,       // % از عرض
      y: -10,                        // از بالا شروع می‌کند
      rotation: Math.random() * 360,
      speed: 0.3 + Math.random() * 0.7,
      drift: (Math.random() - 0.5) * 2,   // انحراف افقی = باد
      size: 8 + Math.random() * 12,
      delay: Math.random() * 5000,
    }));
  }, []);

  return (
    <div className="fixed inset-0 pointer-events-none overflow-hidden z-0">
      {particles.current.map((p) => (
        <PaperLeaf key={p.id} particle={p} />
      ))}
    </div>
  );
};

const PaperLeaf = ({ particle: p }) => (
  <motion.div
    className="absolute opacity-20"
    style={{ left: `${p.x}%`, top: "-20px", width: p.size, height: p.size * 1.4 }}
    animate={{
      y: ["0vh", "110vh"],
      x: [0, p.drift * 80, p.drift * 40, p.drift * 120],
      rotate: [p.rotation, p.rotation + 360 * (Math.random() > 0.5 ? 1 : -1)],
    }}
    transition={{
      duration: 8 + Math.random() * 6,
      delay: p.delay / 1000,
      repeat: Infinity,
      ease: "linear",
    }}
  >
    {/* شکل کاغذ ساده */}
    <svg viewBox="0 0 10 14" fill="none">
      <rect x="1" y="1" width="8" height="12" rx="0.5"
            fill="#a8a29e" stroke="#78716c" strokeWidth="0.5" />
      <line x1="2.5" y1="4" x2="7.5" y2="4"
            stroke="#78716c" strokeWidth="0.4" opacity="0.5" />
      <line x1="2.5" y1="6" x2="7.5" y2="6"
            stroke="#78716c" strokeWidth="0.4" opacity="0.5" />
      <line x1="2.5" y1="8" x2="5.5" y2="8"
            stroke="#78716c" strokeWidth="0.4" opacity="0.5" />
    </svg>
  </motion.div>
);
```
