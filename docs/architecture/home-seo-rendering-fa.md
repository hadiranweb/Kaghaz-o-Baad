# مبنای SEO برای محتوای قابل‌اسکرول Home

## تصمیم طراحی

Home دو لایهٔ مکمل دارد. لایهٔ اول، تجربهٔ تعاملی و مسئله‌محور React است که پس از بارگذاری جاوااسکریپت نمایش داده می‌شود. لایهٔ دوم، همان توضیح people-first، headingهای روشن و لینک‌های داخلی کلیدی را به HTML اولیهٔ prerender شده برای `/`، `/fa` و `/en` اضافه می‌کند. بنابراین crawler یا کاربری که جاوااسکریپت را اجرا نکند، همچنان هدف پلتفرم و مسیرهای اصلی آن را می‌بیند.

محتوای پایین صفحه به‌جای متن انبوه یا تکرار کلیدواژه، با دو بخش مستقل طراحی شده است: معرفی شفاف پلتفرم و «رویکرد انتشار تا گفت‌وگوی ادامه‌دار». همچنین مسیرهای مقاله، رسانه، جلسهٔ زنده، شرح پروژه و درباره با متن لینکِ توصیفی و href واقعی در اختیار کاربر قرار می‌گیرند.

## مبنای منابع

Google Search Central توصیه می‌کند محتوای اصلی برای انسان مفید، قابل‌اعتماد و با هدف روشن ساخته شود؛ متن صرفاً برای دست‌کاری رتبه ایجاد نشود. همچنین راهنمای SEO Starter Guide تأکید می‌کند crawler باید بتواند اجزای مهم صفحه را همان‌گونه که کاربر می‌بیند دریافت کند، و متن سازمان‌یافته و headingهای خوانا به تجربهٔ کاربر کمک می‌کنند.

راهنمای Link Best Practices گوگل بیان می‌کند که لینک‌های قابل‌خزش باید از عنصر `a` با `href` واقعی استفاده کنند و anchor text باید کوتاه، توصیفی و مرتبط با مقصد باشد. همهٔ لینک‌های Home از همین الگو پیروی می‌کنند.

| منبع | نکتهٔ استفاده‌شده | URL |
|---|---|---|
| Google Search Central: Creating helpful, reliable, people-first content | هدف محتوای Home، توضیح واقعی ارزش پلتفرم برای کاربر است؛ نه keyword stuffing یا متن صرفاً رتبه‌محور. | https://developers.google.com/search/docs/fundamentals/creating-helpful-content |
| Google Search Central: Link best practices | لینک‌های داخلی Home از `a[href]` و متن توصیفی مقصد استفاده می‌کنند. | https://developers.google.com/search/docs/crawling-indexing/links-crawlable |
| Google Search Central: SEO Starter Guide | محتوای اصلی Home در HTML prerender شده نیز قرار می‌گیرد و ساختار heading و متن قابل‌فهم دارد. | https://developers.google.com/search/docs/fundamentals/seo-starter-guide |

## مرز Studio

این کار هیچ قابلیت Studio یا provider خارجی را فعال نمی‌کند. کادر مسئله‌محور همچنان فقط جست‌وجوی مقالات منتشرشده را اجرا می‌کند. محتوای SEO نیز هیچ دادهٔ حساب کاربر، نمونهٔ Studio یا متن تولیدشدهٔ runtime دریافت نمی‌کند.
