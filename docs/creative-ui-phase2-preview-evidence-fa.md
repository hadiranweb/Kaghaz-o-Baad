# شواهد preview مرحلهٔ دوم

در preview محلی مسیر `/read`، صفحهٔ آرشیو با عنوان «مقالات» بارگذاری شد و پس از پایان loading، toolbar «قفسهٔ مقالات» با سه کنترل قابل دسترس «قفسه»، «شبکه» و «فهرست» نمایش داده شد. کنترل فعال با `aria-pressed` مشخص می‌شود و empty state موجود backend بدون مقاله، متن «هنوز مقاله‌ای در این دسته وجود ندارد» را نشان داد.

در این preview دادهٔ مقاله‌ای از API برنگشت؛ بنابراین ظاهر جلدها روی دادهٔ واقعی قابل مشاهده نبود، اما مسیر rendering، toolbar و fallback بدون خطای runtime کار کرد. build و SEO verification نیز موفق هستند.

در preview مسیر `/about-project`، شش anchor قابل مشاهده و قابل کلیک بودند: «مسئله و راه‌حل»، «سه گام»، «مزیت‌ها»، «مخاطبان»، «پرسش‌ها» و «کالبد فنی». صفحهٔ Hero مرحلهٔ اول نیز بدون شکست باقی ماند و Progress/TOC پایین Hero با layout راست‌به‌چپ در viewport دسکتاپ نمایش داده شد.

`npm run lint` کامل پروژه به‌دلیل ۲۳ خطای موجود در فایل‌های نامرتبط شکست خورد؛ این خطاها عمدتاً `any`، empty interface/block و import قدیمی هستند. lint اختصاصی فایل‌های تغییرکردهٔ مرحلهٔ دوم بدون error اجرا شد. `npm run build`، `npm run verify:seo` و `git diff --check` موفق بودند.
