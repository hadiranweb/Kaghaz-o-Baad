نصب‌کنندهٔ کاغذ و باد

این ابزار یک کپی محلی از repository می‌سازد و آن را برای استقرار آماده می‌کند. secretهایی که شما وارد می‌کنید در فایل‌های server-side همین workspace نوشته می‌شوند؛ در repository عمومی، frontend، log و manifest ذخیره نمی‌شوند.

این EXE باید داخل پوشهٔ repository اجرا شود یا در یکی از زیرپوشه‌های آن قرار داشته باشد. انتخاب دستی فایل یا ZIP لازم نیست.

تنظیمات پیشرفتهٔ سرویس‌ها و tokenها

در مسیر Liara، installer اطلاعات را برای PaaS، DBaaS، Object Storage و سرور جداگانهٔ LiveKit در workspace محلی ثبت می‌کند. secretها در backend/.env نوشته می‌شوند و نباید این workspaceٔ مقداردهی‌شده را عمومی یا در Git منتشر کنید. اجرای واقعی deployment بعد از بررسی و تأیید انجام می‌شود.
