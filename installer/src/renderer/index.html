نصب‌کنندهٔ کاغذ و باد

این ابزار یک کپی امن از repository می‌سازد و آن را برای استقرار آماده می‌کند. secretها در repository عمومی ذخیره نمی‌شوند.

در مسیر Liara، installer اطلاعات را برای PaaS، DBaaS، Object Storage و سرور جداگانهٔ LiveKit در workspace ثبت می‌کند. اجرای واقعی deployment بعد از بررسی و تأیید انجام می‌شود.
